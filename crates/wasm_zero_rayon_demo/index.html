Parallel Mandelbrot — wasm_zero + rayon, sandboxed via exu

The fractal is computed in WebAssembly with rayon. "Single thread" runs it on one worker; "Multi thread" spreads the rows across navigator.hardwareConcurrency workers sharing one linear memory. The RGBA result is read zero-copy from shared memory and blitted to the canvas. Workers are pooled/reused; the wasm memory is dropped per run.
