wasm_zero: a DOM-free UI — events in, pixels out

The entire UI (sidebar, button, fractal) is rendered in Rust (wasm32-unknown-unknown, #![no_std]). JS owns only the <canvas> and its listeners: it pumps the mouse state into render(mx, my, down, cx, cy) as scalar args, and paints the returned zero-copy Uint8Array with putImageData. Click PAUSE, then move the mouse over the fractal to drive the Julia constant. UI state lives in wasm memory.
