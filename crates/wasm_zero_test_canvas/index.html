wasm_zero: heavy compute in Rust → zero-copy pixels → canvas

Each frame, Rust (in wasm32-unknown-unknown, #![no_std]) iterates z = z² + c for every pixel — an animated Julia set — and stamps HELLO WORLD on top. The RGBA buffer is returned through wasm_zero as a Uint8Array view over wasm memory (no copy on the read side), then blitted with putImageData.
